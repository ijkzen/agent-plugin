# agent-plugin

Claude Code plugin. Configuration in progress — components (skills, agents, hooks) will be added step by step.

## Installation

```bash
# From GitHub marketplace
claude plugin add github:ijkzen/agent-plugin

# Or from local directory (development)
claude --plugin-dir /path/to/agent-plugin
```
